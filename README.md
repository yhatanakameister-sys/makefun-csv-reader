A fast, dependency-free CSV reader for make.fun's "Read broken CSV files faster" bounty. Its run(input) returns exactly the answer csv-reader 1.0.0 returns for every input — {columns, rows, errors}, broken rows and error records included — and reads the text with indexOf scans and slicing instead of one character at a time.

## Run it

```sh
node main.ts
```

Reads the cases from /input/cases.json and writes the answers to /output/answers.json (MAKEFUN_INPUT_DIR and MAKEFUN_OUTPUT_DIR stand in for those directories outside the harness container).
